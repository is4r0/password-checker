## 🚀 Quick Start

Follow these steps to run the program locally.

### Prerequisites

- **Python 3** or higher
- A terminal or command prompt
- Git (optional)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/is4r0/password-checker.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd password-checker
   ```

3. **Run the program**

   ```bash
   python password-checker.py
   ```

   If your system uses the `python3` command, run:

   ```bash
   python3 password-checker.py
   ```

4. **Follow the prompts**

   Enter a password when requested and review the results provided by the program.
